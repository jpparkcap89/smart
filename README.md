# 2026 스마트교육 동계 페스티벌

행사 안내·참가 신청·문의로 구성된 반응형 웹사이트입니다.

- 웹사이트: https://smart.cap89.com/
- GitHub Pages: https://jpparkcap89.github.io/smart/
- 행사: 2026년 11월 21일(토) 10:00–17:50, 목원대학교 사범관 4층

## 현재 상태

참가 신청은 Google Apps Script를 통해 Google Sheets에 저장하도록 연결합니다. 접수 서버 설정을 확인하지 못하거나 접수가 비활성화되어 있으면 신청을 차단합니다. 관리자 비밀번호는 4자 이상 입력 검증만 수행하며 실제 인증하지 않습니다. 수료증은 이름·소속 표기 확인만 제공합니다.

## 구성

`index.html`, `style.css`, `cap89.css`, `lucian-base.css`, `app.js`를 저장소 루트에서 정적 제공하며 별도 빌드가 필요하지 않습니다. 기존 `CNAME`을 유지합니다.

## 참가 신청서 및 포스터 확인

참가 신청서에는 성명·소속·연락처·이메일, 오전·오후 각 1개 트랙 선택, 개인정보 수집·이용 동의, 현장 사진·동영상 촬영·활용 동의, 행사 인지 경로, 향후 희망 주제를 필수 항목으로 제공합니다. 동의 항목은 각각 동의·비동의를 선택하며 모든 답변을 신청 내용 확인에서 확인합니다. 서버에서 접수를 활성화한 경우 최종 접수 단계에서 저장합니다.

메인 화면 포스터를 클릭하면 확대 대화상자를 엽니다. 닫기 버튼, Esc, 바깥 영역 클릭으로 닫을 수 있습니다. 포스터 원본은 `assets/festival-poster.gif`에 포함하여 외부 Google 이미지 주소에 의존하지 않습니다. 주최 (사)스마트교육학회와 주관 목원대 AI중심대학사업단·AI융합교육학회·(사)ICT플랫폼학회를 메인 화면에 표기합니다.

행사는 10:00–17:50이며 정기총회를 포함한 전체 일정은 18:30까지입니다. 개발 시 저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`로 실행할 수 있습니다.

### 실제 접수 연동

프론트엔드는 GitHub Pages, 백엔드는 기존 Google Apps Script, DB는 Google Sheets를 사용합니다. 연결 설정은 `registration-config.js`, 통신 코드는 `registration-api.js`에 있습니다. 상세 내용은 [접수 연동 안내](apps-script/README.md)를 참고하세요.

기존 서버 형식대로 URL-encoded `payload` 안에 JSON을 전송합니다. `Settings`에서 동의 버전·보유 기간·촬영 활용 범위·접수 활성 여부를 읽고, `Programs`와 정확히 일치하는 트랙 값을 보냅니다. 개인정보 동의와 수료증 표기 확인은 필수이며 촬영 비동의는 허용합니다. 인지 경로는 서버가 허용하는 5개 선택지로 제공합니다. 저장 응답과 접수번호를 확인한 경우에만 완료를 표시합니다.

공개 설정 조회는 정상 동작합니다. 현재 서버의 registrationEnabled가 false여서 접수가 닫혀 있으며, 실제 저장 확인은 접수 활성화 후 진행해야 합니다. Apps Script 배포의 실행 사용자는 ‘나’, 액세스 권한은 ‘모든 사용자’여야 공개 접수를 받을 수 있습니다. 실제 DB 저장 검증은 별도로 필요합니다.

관리자 비밀번호와 참가자 데이터는 공개 저장소에 저장하지 않습니다. 관리자 화면은 입력 조건만 확인하며 실제 인증을 수행하지 않습니다. 공개 접수 전 참가비·접수 기간·문의처·개인정보 처리 주체 및 보유 기간·출석과 수료 기준을 확인해야 합니다.
